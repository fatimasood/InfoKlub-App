# 📱 InfoKlub  
🔒 **Smart Personal Information Manager**  

InfoKlub is a smart app to securely manage your **personal, educational, medical, and career information** — all in one place.  

It goes beyond storage with features like:  
✅ Drag & Drop File Uploads  
✅ AI-powered CV / Resume Generation  
✅ Real-time Updates & Smart Reminders  
✅ Goal Tracking & Progress Monitoring  
✅ Bank-level Data Encryption for privacy  

---

## 🚀 Features  

- 📂 Organize documents across multiple categories (education, medical, career, personal).  
- 🧠 Generate professional CVs using AI from stored data.  
- ⏰ Stay on track with reminders & goal-setting modules.  
- 🛡️ Secure data storage with Firebase + local encryption.  

---

## 🛠️ Tech Stack  

- **Frontend:** Flutter (cross-platform, responsive UI)  
- **Backend & Storage:** Firebase + Hive (offline DB)  
- **Encryption:** `encrypt` + `flutter_secure_storage`
